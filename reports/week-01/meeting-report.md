## Summary

- The project aims to build a web application for learning foreign words (specifically German) in the context of full sentences.
- The application will generate flashcards containing the target words within sentences of a predictable, fixed length to help estimate learning session times.
- The customer's current solution, Songs2Anki, is too tedious to use because it requires manual script execution, text conversion, CSV filtering, and manual removal of bad sentences.
- The new system should automate these processes and provide an improved interface for filtering words and editing flashcards.
- The application will feature two main user roles: a student and a teacher.
- The teacher will serve as the "ultimate oracle" who can review student decks, edit sentences, and delete bad sentences generated by the LLM.
- The two most important features to develop are: 1) A card editor for marking bad cards, directly editing sentences, reordering words, and requesting audio generation; 2) A word picker tool that allows users to select words they want to learn and mark words they want to ignore directly from a provided text.
