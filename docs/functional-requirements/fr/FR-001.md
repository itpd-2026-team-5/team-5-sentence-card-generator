# FR-001: Bring In A Text

- **Status:** Active
- **Traces to:** [`US-01`](https://github.com/itpd-2026-team-5/team-5-sentence-card-generator/issues/30), [`CON-01`](../../product-vision.md#con-01), [`DEC-046`](../../decisions.md#dec-046), [`DEC-047`](../../decisions.md#dec-047)
- **Containers:** `frontend`, `backend`

## Behavior

When a learner saves a title and a pasted plain text, the product shall keep the text in the learner's library, visible only to that learner.

When the learner gives a source address or notes with the text, the product shall keep them apart from the text, so they never appear among the words to mark.

When the learner drags a text to a new place in the library, the product shall keep that order the next time the library is opened.

When the learner edits a text, the product shall keep the cards already generated from it unchanged.

## Acceptance Criteria

### AC-01

Given a signed-in learner, when they save the title `Am Bahnhof` and a German paragraph, then the library lists `Am Bahnhof`, and another learner's library does not.

### AC-02

Given a text saved with the source address `https://www.dwd.de/` and a note, when the learner opens it in the reader, then the address is shown as a link above the text and none of its parts can be marked as a word.

### AC-03

Given three texts A, B, C, when the learner moves C to the top and reloads the page, then the library lists C, A, B.

### AC-04

Given a card generated from a text, when the learner deletes a sentence from that text, then the card's sentence, translation, and source sentence are unchanged.
