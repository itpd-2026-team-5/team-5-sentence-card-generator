# FR-014: Expose Operating Signals

- **Status:** Active
- **Traces to:** [VP-01](../../research/value-proposition.md#vp-01)
- **Containers:** `backend`

## Behavior

For each completed backend HTTP request, the product shall export the request duration histogram point and structured log point in [the observability plan](../../observability.md#the-signals) to its environment's OpenObserve organization. The response shall carry the request ID used by the log point.

## Acceptance Criteria

### AC-01

Given staging telemetry is configured, when a request fails, then its response ID finds one log point with route, outcome, and duration, and the five-minute `SLI-01` chart has a numeric failure series.

### AC-02

Given telemetry is disabled, when a request completes, then the product still responds without contacting OpenObserve.
