# FR-013: Record Core Task Events

- **Status:** Active
- **Traces to:** [VP-02](../../research/value-proposition.md#vp-02)
- **Containers:** `backend`

## Behavior

When a learner adds a text, marks a word, generates cards, and saves a study rating, the backend shall emit the corresponding event from [the event table](../../analytics.md#the-events). It shall also record a failed generation attempt and a teacher's card approval. Each event shall contain the documented fields, `source`, and `environment`, and no personal content.

## Acceptance Criteria

### AC-01

Given telemetry is configured for staging, when the core task is completed, then the staging project receives each documented event with `source=web` and `environment=staging`.

### AC-02

Given a staging pipeline check, when an event is sent with `source=smoke`, then it appears in the event list but is excluded from every metric query. Production receives no check event.

### AC-03

Given telemetry is disabled or incomplete, when the core task is completed, then the product still responds normally and no export is attempted.
