# FR-005: Write Sentences With The Learner's Own Key

- **Status:** Active
- **Traces to:** [`DEC-019`](../../decisions.md#dec-019), [`DEC-027`](../../decisions.md#dec-027), [`DEC-028`](../../decisions.md#dec-028), [`ADR-002`](../../architecture/adr/ADR-002.md)
- **Containers:** `frontend`

## Behavior

When a learner chooses their own key in Settings, the product shall keep the provider, address, model, and key in that browser only.

While the learner's own key is chosen, the product shall send each generation request from the browser straight to the learner's provider and shall send the key to no other address.

When the learner chooses the service instead, the product shall write sentences with the service's key and model, and shall keep using it until the learner switches back.

## Acceptance Criteria

### AC-01

Given a learner who saved an Anthropic key in Settings, when they generate cards, then the browser's network log shows the request with the key going to the provider's address, and no request to the product's own server carries the key.

### AC-02

Given that learner, when they open the product in another browser, then Settings shows the service selected and no key.

### AC-03

Given a learner with a saved key, when they choose the service and generate cards, then no request goes from the browser to the provider.
