# FR-004: Skip A Card The Deck Already Has

- **Status:** Active
- **Traces to:** [`US-03`](https://github.com/itpd-2026-team-5/team-5-sentence-card-generator/issues/32), [`DEC-012`](../../decisions.md#dec-012), [`DEC-043`](../../decisions.md#dec-043)
- **Containers:** `backend`

## Behavior

When cards are generated into a deck, the product shall skip a marked word for which that deck already has a card with the same word from the same source sentence.

The product shall still create a card for the same word marked in a different sentence, and for the same word generated into a different deck.

When a learner asks for another sentence for a word, the product shall add it as a new card with its own review progress.

## Acceptance Criteria

### AC-01

Given a deck with a card for `Bank` from `Ich sitze auf der Bank im Park.`, when cards are generated again from the same text into that deck, then no card is created.

### AC-02

Given that deck, when `Bank` is marked in `Ich bringe das Geld zur Bank.` and cards are generated, then a second card for `Bank` is created.

### AC-03

Given a card for `Bank` in deck A, when the same text is generated into deck B, then deck B gains a card for `Bank`.

### AC-04

Given a card that has been reviewed once, when the learner asks for one more sentence for its word, then a new card exists with no reviews, and the first card's next review date is unchanged.
