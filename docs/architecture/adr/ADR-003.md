# ADR-003: Check Each Sentence And Ask Again With The Reason

- **Status:** Accepted
- **Created:** 2026-10-24
- **Updated:** 2026-10-24
- **Containers:** `backend`
- **Addresses:** [`FR-003`](../../functional-requirements/fr/FR-003.md), [`FR-004`](../../functional-requirements/fr/FR-004.md), [`QR-03`](../../quality-requirements/qr/QR-03.md), [`QR-04`](../../quality-requirements/qr/QR-04.md), [`QR-05`](../../quality-requirements/qr/QR-05.md)
- **Decision:** [`DEC-043`](../../decisions.md#dec-043), [`DEC-048`](../../decisions.md#dec-048)

## Context

An LLM sometimes writes a sentence without the target word, longer than the learner's bounds, or with a word the learner chose to ignore, and some gateways ignore a request for structured output and wrap the JSON in text.
The Customer wants such sentences written again before they are shown as ready ([`DEC-048`](../../decisions.md#dec-048)) and a word not to be generated twice for the same context in one deck ([`DEC-043`](../../decisions.md#dec-043)), while waiting time and cost must stay bounded.

## Considered Options

- **Check in the backend, and ask again for the failed sentences only, with the failed checks as feedback, up to three attempts.**
  The cost of a retry is paid only for the cards that failed, and the model is told what to fix.
- **Show every sentence and let the learner fix it.**
  No extra requests, but the learner studies bad cards, which [`DEC-048`](../../decisions.md#dec-048) rejects.
- **Retry until every sentence passes.**
  Every card would pass, but a model that cannot meet a tight bound would loop, and the cost and the waiting have no limit.

## Decision Outcome

Chosen option: check in the backend and ask again with the reason, up to three attempts in all; a card that still fails is saved as flagged and kept out of study.
Before the request, the backend skips each marked word that the deck already has from the same source sentence.
The answer is read as JSON even when the provider wraps it in text, and an answer that cannot be read is an LLM error.

## Consequences

- **Functional Suitability:** fewer cards that break the learner's bounds reach study; [`QR-03`](../../quality-requirements/qr/QR-03.md) measures what share the learner keeps.
- **Performance Efficiency:** a text with failing sentences takes up to three LLM round trips, which [`QR-04`](../../quality-requirements/qr/QR-04.md) bounds at 60 seconds for five words.
- **Reliability:** an unreadable answer becomes a message to the learner rather than a broken card, which [`QR-05`](../../quality-requirements/qr/QR-05.md) checks.
- **Cost:** each retry costs tokens, and the checks cover only what code can check, not whether the sentence is natural.
