# ADR-006: Export Product Events To OpenPanel

- **Status:** Proposed
- **Created:** 2026-11-07
- **Updated:** 2026-11-07
- **Containers:** `backend`
- **Addresses:** [FR-013](../../functional-requirements/fr/FR-013.md)

## Context

The product needs measurable core-task use in staging and production without exporting learner content or adding a dependency to the normal request result.

## Considered Options

- **Server-side OpenPanel events:** the backend sends a small field allowlist to separate projects.
- **Browser analytics:** easier page events, but this task is defined by backend writes and browser tooling could add unwanted context.

## Decision Outcome

Choose backend event emission to self-hosted OpenPanel projects, with separate write credentials and `TELEMETRY_ENABLED` control. The event table in [analytics](../../analytics.md#the-events) is the contract.

## Consequences

- **Confidentiality:** only enumerated fields are sent; no learner content is included.
- **Cost:** deployment needs an OpenPanel instance and two projects. Event export failures are logged without failing the core task.
