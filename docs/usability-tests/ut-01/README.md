# UT-01: Create a sentence card from a chosen text

- **Status:** Planned
- **Design sprint:** [SPRINT-07](../../project-plan.md#sprint-07)
- **Run sprint:** [SPRINT-08](../../project-plan.md#sprint-08)

Assess whether a representative language learner can turn a word they chose from their own text into a sentence card they keep for study without help.

Research questions:

1. Can a representative learner select a word from their text and create a sentence card they choose to keep without facilitator help?
2. Where do learners encounter friction or request help while selecting a word, generating a sentence, and keeping the card?
3. How do learners rate the ease of the main and secondary usability test tasks?
